# Pluvianidae

# 1. Instalar Electron (primera vez)
npm run mascot:install

# 2. Compilar la extensión
npm run compile

# 3. Compilar la mascota
npm run mascot:build

# 4. Ejecutar tests (416 unit + property + 10 integration = 426 total)
npm test

# 5. Desarrollo simultáneo (extensión + mascota Electron)
npm run dev

# 6. Solo la mascota en desarrollo (watch + electron)
npm run mascot:dev

# 7. Probar desde VS Code: F5 → Extension Development Host
#    La mascota debería aparecer flotando en la esquina inferior derecha
